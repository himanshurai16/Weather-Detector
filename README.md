# 🌦️ Advanced Weather Forecast Dashboard

An advanced and responsive weather forecasting web application that provides real-time weather updates, hourly forecasts, and a 7-day weather forecast through an interactive dashboard.

## ✨ Features

- 🌡️ **Current Weather:** Temperature, feels-like temperature, and weather conditions.
- 🕒 **Hourly Forecast:** Weather predictions for the next 24 hours.
- 📅 **7-Day Forecast:** View upcoming weather conditions.
- 📊 **Temperature Charts:** Interactive weather graphs using Chart.js.
- 🌧️ **Precipitation Probability:** Check the chance of rainfall.
- ☀️ **UV Index:** View ultraviolet radiation levels when available.
- 💨 **Wind Information:** Wind speed and direction.
- 🌫️ **Air Quality:** Air quality information when supported by the selected API.
- 🔍 **City Search:** Search weather information for different cities.
- 📱 **Responsive Design:** Works on desktops, tablets, and mobile devices.
- ⚠️ **Error Handling:** Displays appropriate messages for invalid cities and API errors.

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling and responsive design
- **JavaScript** — Dynamic functionality and API integration
- **Chart.js** — Interactive weather charts
- **Weather API** — Live weather and forecast data

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Register with a weather API provider and obtain an API key.
4. Configure the API key according to the provider's instructions.
5. Run the project using the VS Code Live Server extension or another local web server.
6. Search for a city to view its weather information.

**Note:** Some features may require an API plan that supports hourly forecasts, air quality, or other advanced weather data.
